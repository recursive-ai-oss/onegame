The onegame command: create, build, run, test, capture and replay games.

**Package:** `RecursiveAI.OneGame.Cli`

```sh
dotnet add package RecursiveAI.OneGame.Cli
```

This package has no public .NET API: it ships a command or build files, which the guides describe.
