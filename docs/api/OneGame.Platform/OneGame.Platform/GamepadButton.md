# GamepadButton enum

**Namespace:** `OneGame.Platform`  
**Package:** [`RecursiveAI.OneGame.Platform`](../index.md)

```csharp
public enum GamepadButton : byte
```

A button on the standard gamepad layout. Names follow the physical position, so South is A on an Xbox pad and Cross on a PlayStation pad.
